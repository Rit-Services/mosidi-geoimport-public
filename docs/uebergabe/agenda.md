# Agenda der Übergabesitzung für Entwickler*innen (ca. 2,5 h, vor Ort oder per Video)

| Zeit | Thema | Ergebnis |
|---|---|---|
| 0:00–0:10 | Ziel, Lieferumfang, Abnahmekriterien (LB 8, LB 11) | gemeinsames Verständnis |
| 0:10–0:30 | Architektur und Ablauf eines Laufs, Löschen + Ersetzen je Quelle, `pipeline_meta` | Diagramme erklärt (`docs/architektur.md`) |
| 0:30–0:50 | Live: Installation aus dem Repository, `.env`, `docker compose up`, `validate-config`, `check-target` | läuft bei der TH |
| 0:50–1:15 | Live: manueller Lauf WFS + CSV, Bericht lesen, Fehlerfall simulieren (Quelle aus) | E2E gemeinsam gesehen |
| 1:15–1:25 | Pause | |
| 1:25–1:55 | Übung: neue Quelle per YAML anbinden (WFS-FeatureType `app:krs`, CSV-Spalten) | eine Entwickler*in der TH hat selbst eine Quelle angebunden |
| 1:55–2:10 | Betrieb: Zeitplan, Logs, Aufbewahrung, Aktualisierung, Störungsbehebung | Betriebshandbuch durchgegangen |
| 2:10–2:20 | Erweiterung: neuer Quelltyp, neuer Ziel-Adapter, Tests, Release | Entwicklerdoku bekannt |
| 2:20–2:30 | Offene Punkte, Abnahmetest durch die TH, Repository-Übertragung, Abschluss (keine Betriebsbegleitung danach, A8) | Protokoll, nächste Schritte der TH |
